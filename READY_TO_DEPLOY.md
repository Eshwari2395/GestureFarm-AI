## 🚀 Getting Started

### 5-Minute Setup
```bash
# 1. Clone
git clone <repo>
cd mitti-mitra

# 2. Install
npm install

# 3. Configure
cp .env.example .env.local
# Edit with Supabase credentials

# 4. Run
npm run dev

# 5. View
# Visit http://localhost:5173
```

### Deploy to Production
```bash
# Vercel (easiest)
vercel --prod

# Docker
docker-compose up -d

# Netlify
netlify deploy --prod
```
